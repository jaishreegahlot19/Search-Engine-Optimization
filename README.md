# 💎 Aurelia Jewellery – SEO Case Study

A professional Digital Marketing project focused on implementing Search Engine Optimization (SEO) strategies for the Aurelia Jewellery website.

## 📌 Project Overview

This project demonstrates how SEO techniques can improve website visibility, organic traffic, and search engine rankings for a jewellery brand.

The presentation includes:

- Keyword Research
- Primary & Secondary Keywords
- Search Intent Analysis
- On-Page SEO
- SEO-Friendly URL
- Title Tags
- Meta Description
- Heading Structure (H1, H2)
- Semantic HTML
- Mobile-Friendly Design
- Off-Page SEO
- Backlink Strategy
- Guest Posting
- Social Media Marketing
- Competitor Analysis
- Technical SEO
- XML Sitemap
- robots.txt
- SEO Conclusion

## 🛠️ Tools Used

- Wix Studio
- Google Search
- Canva
- SEO Best Practices
